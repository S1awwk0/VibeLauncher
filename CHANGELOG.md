# Changelog

Все заметные изменения проекта. Формат версий: `MAJOR.MINOR.PATCH`.

## [1.0.0] — 2026-11-08

Первый публичный релиз Vibe Launcher.

### Добавлено

- Лаунчер Minecraft для Windows на WPF (.NET 10) с русским интерфейсом.
- Аккаунты Microsoft (OAuth device-code) и офлайн-аккаунты по никнейму.
- Установка ванильных версий Minecraft, ассетов и библиотек.
- Автоматическая установка Fabric, Quilt, Forge и NeoForge.
- Сборки с отдельными папками `mods`, `config`, `saves`.
- Поиск и установка модов с Modrinth, импорт `.mrpack`.
- Скины Mojang и Ely.by, импорт скинов TLauncher, установка `CustomSkinLoader`.
- Анализ логов и причин вылетов.
- Настройки памяти, Java, размера окна и полноэкранного режима.
- Установщик MSI (self-contained, без отдельной установки .NET Runtime).
- В установщике можно выбрать создание папки в меню «Пуск» и ярлыка на рабочем столе.
- Иконка приложения и брендинг Vibe Launcher.

### Исправлено

- Заголовки секций интерфейса больше не сливаются с тёмным фоном.
- Флажок снапшотов теперь корректно выключается и синхронизирован между страницами «Версии» и «Настройки».
- Версия Minecraft при установке загрузчика и создании сборки выбирается из списка релизов Mojang, а не вводится вручную.
- NeoForge на Java 25: принудительный выбор Java 21 и `-DignoreList` для jar игры.
- Загрузка NeoForge через официальное зеркало CreeperHost.
- Устойчивость входа Microsoft к не-JSON ответам сервера.
- Дополнены шаблоны анализа крашей: конфликты модов, модулей Java, `NoSuchMethodError`.

### Установка

Скачайте `VibeLauncher-Setup-1.0.0-win-x64.msi` из релиза и запустите.
Установка не требует прав администратора, данные сохраняются в `%APPDATA%\VibeLauncher`.
